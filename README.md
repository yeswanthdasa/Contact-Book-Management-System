Contact Book Management System

Project Description

A simple Contact Book Management System developed using Python functions and dictionaries.

Features

- Add Contact
- Search Contact
- Update Contact
- Delete Contact
- View All Contacts
- Exit Application

Technologies Used

- Python
- Functions
- Dictionaries
- Loops
- Conditional Statements

How to Run

1. Download the Python file.
2. Open it using Python.
3. Run the program.
4. Select an option from the menu.
